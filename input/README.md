# Original video goes here

Download the Video Overview from NotebookLM (open the video → ⋮ → **Download**) and upload the MP4 to this folder as `original.mp4`.

- GitHub web upload (**Add file → Upload files**) accepts files up to 25 MB.
- Larger files: attach the MP4 to a GitHub **Release** of this repository (up to 2 GB), or push it with git (up to 100 MB).
