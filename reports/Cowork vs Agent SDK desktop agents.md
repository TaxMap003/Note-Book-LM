# Roy Belongs on the Agent SDK

**Build Roy and the agents after him as a custom app on the Claude Agent SDK, not on Cowork.** As of 3 October 2026, Cowork fails several hard requirements at once. From **6 October 2026**, new Cowork tasks on Pro and Max run in Anthropic's cloud, and the "Only on your computer" setting goes away ([Claude Help](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile)). When computer use opens a desktop app, Claude must be allowed in for that one session only. So an unattended 9 a.m. run stops at a prompt nobody is there to click ([Claude Code Docs](https://code.claude.com/docs/en/desktop)). And Claude in Chrome refuses "purchases or financial transactions" **whatever the permission settings** ([Claude Help](https://support.claude.com/en/articles/12902446-claude-in-chrome-permissions-guide)). With the SDK, the firm's own code can hold any action until the owner taps Approve on his phone, however long that takes ([Agent SDK docs](https://code.claude.com/docs/en/agent-sdk/user-input)). The price is engineering work plus API charges of roughly **$100–$160 per agent per month**. Cowork stays useful for drafting playbooks and for email or research jobs. Neither route makes "the AI clicks Pay" safe or clearly allowed. Early jobs should stop at a review screen and leave the final submit to a human.

## Cowork falls short on most requirements; the SDK meets them only once built

| Requirement | Cowork (desktop app + computer use + Claude in Chrome) | Custom Agent SDK app |
|---|---|---|
| Runs on the PC on a schedule | After 6 Oct, runs in the cloud; reaches the PC only while the app is open | The firm's own scheduler; the agent runs in the signed-in, unlocked Windows account |
| Unattended desktop apps | Must be allowed in each session; Pro/Max plans only | The firm builds the Windows control code for Anthropic's computer-use tool |
| Chrome portal entry | Uses your real Chrome; pauses at logins and CAPTCHAs | Playwright browser automation, with a separate saved Chrome profile per agent |
| Money-moving step after approval | Blocked by Anthropic's policy | Allowed only when the firm's code finds an approval from the phone |
| Password manager | 1Password for Claude is Mac-only | The firm's code types the password; it never enters Claude's view or the logs |
| Code from the owner's phone | Typed into the chat; stays in the transcript | Sent by Telegram reply, typed in by the firm's code, then erased from logs |
| Phone approvals | Phone alert when Claude needs input; Dispatch (the phone link) closed to new users | The firm builds it (Telegram bot) |
| Teach by recording | Record a skill is Mac-only | The firm builds it (video stills + transcript → playbook) |
| Audit trail | A log of each run; firm-wide log export only on Team/Enterprise | Every action, screenshot and approval, logged by the firm |

## Three Cowork blockers decide the verdict

**Where tasks run.** For work that must stay on one machine, Anthropic now points to Claude Code Desktop, another mode of the same desktop app. Cowork scheduled tasks "don't carry over" to it ([Claude Help](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile)). Its scheduled tasks fire only while the app is open and the PC is awake. If one task is still running when another is due, the second is **skipped, not queued** ([Claude Code Docs](https://code.claude.com/docs/en/desktop-scheduled-tasks)). The Windows app also has open bugs. In one, users cannot save PC-only tasks and are forced to sign in again every 24–36 hours ([GitHub #97341](https://github.com/anthropics/claude-code/issues/97341)). In another, turning on computer use locked Windows **seven times in four minutes** ([GitHub #96412](https://github.com/anthropics/claude-code/issues/96412)).

**Approvals and the money wall.** Computer use is a beta for **Pro and Max only**, not Team or Enterprise plans ([Claude Help](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork)). In Chrome, Claude always asks before entering sensitive information. It is barred from handling "sensitive credit card or ID data". It also hands login pages and CAPTCHAs back to a human ([Claude Help](https://support.claude.com/en/articles/12902446-claude-in-chrome-permissions-guide); [Claude Code Docs](https://code.claude.com/docs/en/chrome)). The password-manager link works only on a Mac ([Claude Help](https://support.claude.com/en/articles/15936181-get-started-with-1password-for-claude)). Dispatch is closed to new users and turns down unanswered requests after **10 minutes** ([Claude docs](https://claude.com/docs/cowork/guide/dispatch)). Anthropic's own advice: "Don't schedule tasks that… make purchases, or take other actions that are difficult to undo" ([Claude Help](https://support.claude.com/en/articles/13364135-use-cowork-safely)).

**Teaching.** Record a skill, Claude's built-in way to learn a job from a screen recording, is "not available… on Windows". It also keeps screenshots of whatever was on screen ([Claude Help](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills)). Claude cannot watch video directly; it reads images and text only ([Claude Docs](https://platform.claude.com/docs/en/build-with-claude/vision)). On either route, a training video must be split into still frames, with the spoken narration transcribed alongside.

## The SDK trades product limits for engineering risk

The SDK's approval controls fit the firm's design. A pending approval "can stay pending indefinitely". For approvals that take hours, the agent can stop and pick up later where it left off ([Agent SDK docs](https://code.claude.com/docs/en/agent-sdk/user-input)). A block placed in the firm's code holds whatever approval setting is in use ([Agent SDK docs](https://code.claude.com/docs/en/agent-sdk/permissions)). If an approval check times out, the step is skipped rather than run, so the system fails safe ([Agent SDK hooks](https://code.claude.com/docs/en/agent-sdk/hooks)). Security guidance from OWASP says not to let the AI decide its own permissions ([OWASP LLM06](https://owasp.github.io/www-project-top-10-for-large-language-model-applications/2_0_vulns/LLM06_ExcessiveAgency.html)). So the firm's code should gate whole business actions, such as "submit payment", rather than single mouse clicks.

The firm still has to build most of the system. Anthropic's computer-use tool decides what to click, but the firm's software must take the screenshots and move the mouse, and Anthropic's only sample runs on Linux ([Claude Docs](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)). Claude Code's built-in screen control is "not available on Linux or Windows" ([Claude Code Docs](https://code.claude.com/docs/en/computer-use)). The four newest Python releases of the SDK ship without Windows support, and new versions come out almost daily ([PyPI](https://pypi.org/project/claude-agent-sdk/)). Build in TypeScript, the SDK's other language, and lock the app to one tested version.

Apps a firm builds itself should be billed through a pay-as-you-go API key ([legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)). Anthropic's phone-control feature (Remote Control) does not work with API keys ([Claude Code Docs](https://code.claude.com/docs/en/remote-control)). So the firm needs its own phone channel. A free Telegram bot works: it gives Approve and Reject buttons, and the PC needs no public web address ([Telegram](https://core.telegram.org/bots/api)). Expect some failures. Even the best model, Opus 5.5, scores **81.8% on a desktop-task benchmark that gives partial credit** ([Anthropic](https://www.anthropic.com/claude-opus-5-5)). Our rough, unsourced estimate is **4–8 developer-weeks** to build a reliable Roy.

## Running costs land near $100–$160 per agent-month

Sonnet 5.5 costs $2 per million input tokens and $10 per million output; Opus 5.5 costs $4 and $20, and cached re-reads cost $0.20 per million on both ([pricing](https://platform.claude.com/docs/en/about-claude/pricing)). Each screenshot costs about 1,000–1,800 tokens ([Claude Docs](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)). From these prices, our model of a typical 45-minute browser-and-desktop run comes to about **$4.70 on Sonnet or $7.30 on Opus with caching**, and $22 or $44 without it. One run per workday puts Roy at **$103–$161 a month**, and five such agents at about $500–$800. Email and research agents cost far less.

Cowork instead costs $20 a month (Pro) or from $100 (Max) ([pricing](https://claude.com/pricing)). But those plans assume "ordinary, individual usage" ([legal](https://code.claude.com/docs/en/legal-and-compliance)). Anthropic's plan to give subscribers separate credits for SDK apps is on hold ([Claude Help](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)). The biggest cost is the developer time to build the app.

## The Windows PC must stay logged on, unlocked and awake

Use **Windows 11 Pro**, which Cowork requires ([GitHub #27906](https://github.com/anthropics/claude-code/issues/27906)). Create a **standard (non-admin) Windows account** that signs in automatically. Microsoft's free Sysinternals Autologon tool does this and stores the password more safely than the plain-text registry method ([Microsoft](https://learn.microsoft.com/en-us/troubleshoot/windows-server/user-profiles-and-logon/turn-on-automatic-logon)). Do software installs from a separate admin account, because admin prompts block the agent's clicks and typing ([Microsoft](https://learn.microsoft.com/en-us/troubleshoot/power-platform/power-automate/desktop-flows/ui-automation/uipi-issues)).

In Task Scheduler, start the agent at sign-in with **"Run only when user is logged on"**. Never run it as a Windows service or with "Run whether user is logged on or not". Those run with no visible desktop, so the agent's screenshots and clicks fail ([Microsoft](https://learn.microsoft.com/en-us/answers/questions/5789906/scheduler-tasks-with-security-options-run-whether)).

Turn off sleep and the lock screen, and fit an HDMI dummy plug so the PC always sees a monitor. Fix the display at **1280x800 with 100% scaling**, as Anthropic advises for web work ([Claude Docs](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)). Avoid Windows Remote Desktop: closing it locks the screen the agent needs ([SmartBear](https://support.smartbear.com/testcomplete/docs/testing-with/running/via-rdp/keeping-computer-unlocked.html)).

Set the PC to switch itself back on after a power cut ([ASUS](https://www.asus.com/support/faq/1049855/)). Turn on BitLocker drive encryption in the mode that needs no PIN at startup ([Microsoft](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/countermeasures)). Limit Windows Update restarts to a weekly overnight window ([Microsoft](https://learn.microsoft.com/en-us/windows/deployment/update/wufb-compliancedeadlines)). Add an outside service that alerts your phone when the PC stops checking in ([Healthchecks.io](https://healthchecks.io/docs/faq/)). Give each agent its own Chrome profile, keep the PC on its own network, and run only one screen-driving agent at a time.

## Compliance and vendor terms need sign-off before go-live

Tax preparers fall under the **FTC Safeguards Rule**. It requires multi-factor sign-in and monitoring of every "authorized user", and an AI agent counts as one ([FTC](https://www.ftc.gov/business-guidance/resources/ftc-safeguards-rule-what-your-business-needs-know)). The IRS sample written information security plan (WISP) breaks three ways on an always-on agent PC. It requires locked unattended computers, bans shared accounts, and limits remote access to staffed hours ([IRS Pub 5708](https://www.irs.gov/pub/irs-pdf/p5708.pdf)). Each conflict needs a written exception approved by the firm's designated security lead. Anthropic advises against giving computer use access to banking or government apps ([Claude Help](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork)). It also makes the user responsible for following each website's rules on automated use ([Claude Help](https://support.claude.com/en/articles/13364135-use-cowork-safely)).

TaxAct's professional software licence now bars "artificial intelligence agents" without written permission ([TaxAct](https://www.taxact.com/professional/legal-notice)). ADP treats anyone using a client's login as an "Unauthorized Third Party", even with consent ([ADP](https://www.adp.com/legal.aspx)). This research did not check the IRS e-Services and ID.me terms, Patriot's payroll terms, IRC §7216 limits on sharing return data with an AI vendor, or Massachusetts 201 CMR 17.00; clear each with counsel or the vendor before go-live.

## Conclusion

The bigger question is which steps an AI should do at all. Vendor terms, identity-verified logins and Anthropic's own advice limit the money and government steps on both routes. So the SDK's real value is not finishing payments. It is a dependable runner that prepares work, stops at a gate the firm controls, and leaves a full audit record.

Start now with the parts that carry over. Write each job's playbook, which works on either route. Pilot email and research in Cowork while the SDK app is built. Pick a first job for Roy that ends at a review screen. Revisit Cowork once the 6 October cloud switch settles.
